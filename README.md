# مِحَكّ الدماغ التحقيقي — `obsidian-investigation-brain`

مهارة (Skill) لبناء وإدارة **Obsidian Vault** كمرجع تحقيقي موثوق، منظم ومقاوم للانحراف والتحيز.

**الإصدار:** 0.1.1  
**مبني على:** [obsidian-research-brain](../obsidian-research-brain/) v1.1.9 ([repo](https://github.com/bio-colab/obsidian-research-brain-skill))

---

## 📌 لماذا هذه المهارة؟

التحقيقات الطويلة والمشروعات التحقيقية المعقدة تنزلق بسهولة إلى:
- اختلاط الأدلة الملموسة بالتخمينات والافتراضات.
- التحيز التأكيدي (Confirmatory Bias) بالبحث فقط عما يدعم الفرضية المفضلة.
- فقدان سلسلة حفظ الأدلة (Chain of Custody).
- خط زمني مبعثر وغير دقيق للأحداث.
- تقارير ختامية تتجاهل الفجوات والأسئلة غير المجاب عنها.

تفرض هذه المهارة وعاءً منظماً، وسلسلة إثبات قابلة للدفاع عنها، ومقاومة صريحة للتحيز، دون استبدال الحكم المهني للمحقق أو الباحث.

---

## ✨ الميزات الرئيسية

- **أربعة أوضاع عمل:** (Scaffold · Management · Audit · Reporting)
- **فصل صارم:** فصل تام بين الأدلة (Evidence)، الفرضيات (Hypotheses)، ومنطقة الاستكشاف.
- **سلسلة حفظ الأدلة (Chain of Custody):** توثيق إجباري للمصدر والتوثيق الحسابي/الزمني.
- **الفرضيات المضادة (Counter-Hypothesis):** إلزامية لكل فرضية رئيسية لمنع الانحياز.
- **الخط الزمني أولاً (Timeline-first):** ربط الأحداث بمرجعية زمنية صارمة.
- **البوابة البشرية (Human Gate):** آلية مراجعة إنسانية وقائمة مراجعة (Review-Queue).
- **Gap Intelligence:** رصد ثغرات الأدلة والفجوات التحقيقية.
- **لوحات Canvas للبروتوكولات:** (Evidence Board · Crime Scene · Timeline · Suspect Profile · Link Analysis).
- **تدقيق آلي:** سكريبت حتمي (`audit_vault.py`) للتحقق من سلامة وصحة الـ Vault.

## 🚀 البداية السريعة (Quick Start)

1. **التفعيل:** فعّل المهارة واطلب بناء Vault قضية بتقديم: (رقم/اسم القضية + النطاق + خطة التحقيق أو المراحل + أدوار الفريق إن وجدت).
2. **الإنشاء:** يعمل الوكيل بـ **الوضع (أ) — Scaffold** لبناء الهيكل.
3. **الإدارة:** أضف الأدلة والكيانات والفرضيات في **الوضع (ب) — Management** (أدلة حقيقية + سلسلة حفظ + Human Gate عند الحاجة).
4. **التدقيق:** استخدم **الوضع (ج) — Audit** أو شغل السكريبت:
   ```bash
   python scripts/audit_vault.py
   ```
5. **التقارير:** شغّل **الوضع (د) — Reporting** لإنتاج التقارير النهائية أو الملفات القضائية.

📖 **دليل المحقق المبسط:** [`references/guide-for-investigator.md`](references/guide-for-investigator.md)

## 🔄 الأوضاع الأربعة (Skill Modes)

| الوضع | النمط | الاستخدام |
| :--- | :--- | :--- |
| **أ — Scaffold** | الإنشاء | بناء Vault القضية من الصفر وتجهيز الهيكل والقوالب |
| **ب — Management** | الإدارة | إضافة وتحديث الأدلة، الكيانات، الفرضيات، والأحداث |
| **ج — Audit** | التدقيق | فحص سلسلة الحفظ، الفرضيات المضادة، ورصد الفجوات |
| **د — Reporting** | التقارير | توليد تقرير قضية متكامل أو ملف تقديم للمحكمة |

## ⚠️ تحذيرات وتنبيهات مهمة

- **الخصوصية:** عند المشاركة أو النشر على منصات مفتوحة المصدر، استخدم قضايا عامة أو تدريبية فقط (مثل ملفات FBI Vault العامة).
- **السرية:** القضايا الحقيقية أو الحساسة يجب أن تبقى محليه ومشفّرة بالكامل (**Local-first & Encrypted**).
- **المسؤولية:** هذه المهارة أداة مساعدة وتنظيمية للمحقق، وليست بديلاً عن الإجراءات القانونية الرسمية أو التقدير القضائي المستقل.
- **النزاهة:** يُحظر استخدام المهارة لاختلاق أدلة، تعديل تواريخ السجلات، أو تزييف الشهادات.
