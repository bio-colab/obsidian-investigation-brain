# Archived Tools Reference

الأدوات المرتبطة بقضية تُؤرشف داخل `08-Tooling/Archive/` وتُرقّى بعد Human Gate إلى `08-Tooling/Library/`. هذا المجلد في مستودع المهارة يشرح مكان المرجع فقط؛ لا تُشغّل منه أدوات تلقائياً ولا تنسخ كوداً إلى قضية دون manifest وfixture وTool-Audit.

استخدم `scripts/tools-review.py --promote <path>` للترقية الصريحة بعد المراجعة، أو `--archive <path>` للأرشفة. لا يوجد حذف تلقائي، لأن سجل الأداة الفاشلة قد يكون مهماً لتفسير النتيجة أو لتدقيق قانوني لاحق.
